## About

This repository is a learning workspace based on **HTML5 Boilerplate**. It provides a standards-friendly HTML starting point together with icons, a web manifest, error page, browser configuration, and Webpack development/production builds.

## Included

- Semantic HTML5 document starter
- CSS and JavaScript entry files
- Web manifest, favicon, and application icons
- `robots.txt` and a custom `404.html`
- Webpack development server
- Optimized production build command

## Run Locally

Requirements: Node.js and npm.

```powershell
git clone https://github.com/tasnimrimi/Htmlboilerplate.git
cd Htmlboilerplate
npm install
npm start
```

Create a production bundle with:

```powershell
npm run build
```

## What I Practised

- Understanding a production-oriented front-end folder structure
- Page metadata, icons, manifests, and browser configuration
- Separating HTML, CSS, and JavaScript
- Local development and production bundling with Webpack
